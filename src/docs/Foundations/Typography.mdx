## Fonts

Components read each font through a CSS custom property, with the family name as fallback (for example `font-family: var(--font-inter, 'Inter'), sans-serif`). Define the property to load the font however your app does; the library itself ships no font files.

### Use your own font loader

With Next.js, bind `Inter Tight` to its variable:

```tsx
import { Inter_Tight } from "next/font/google";

const inter_Tight = Inter_Tight({
  subsets: ["latin"],
  variable: "--font-inter-tight",
});

export default function RootLayout({ children }) {
  return (
    <html className={inter_Tight.variable}>
      <body>{children}</body>
    </html>
  );
}
```

Without a font loader, define the variable yourself, after loading the font:

```css
:root {
  --font-inter-tight: "Inter Tight";
}
```

Storybook loads the fonts listed above itself (see `fonts` in `syncline.config.json`).
