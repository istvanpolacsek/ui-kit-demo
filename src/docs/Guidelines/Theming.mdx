# Theming

Multi-mode variable collections (for example light/dark or device size) are independent **axes**. Select one mode per axis with the ThemeProvider `modes` prop; unspecified axes use their first mode. In Storybook the colour scheme follows the Backgrounds selector and every other axis has its own toolbar control.
