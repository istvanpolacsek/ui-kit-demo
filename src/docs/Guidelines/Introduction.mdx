# ux\-folio

A React component library generated from the Figma design file. Components, tokens and these docs are produced by the UI Kit pipeline; do not edit generated files by hand — change the design and re-sync.

- **Visual asset**: 252 components

## Setup

Wrap your app in the generated provider so components can read design tokens:

```tsx
import { ThemeProvider } from "ux-folio/providers/ThemeProvider";

<ThemeProvider modes={{/* e.g. Color: "Dark" */}}>
  <App />
</ThemeProvider>;
```
