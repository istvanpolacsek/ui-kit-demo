# uxfolio

A React component library generated from the Figma design file. Components, tokens and these docs are produced by the Syncline pipeline; do not edit generated files by hand — change the design and re-sync.

## Components

- **Cover**: \_Asset heading, \_Asset subheading
- **Button**: 44 components
- **Input**: 54 components
- **Panel**: 78 components
- **Overlay**: 66 components
- **Section**: 24 components
- **Visual asset**: 252 components
- **Module**: 37 components

## Setup

Wrap your app in the generated provider so components can read design tokens:

```tsx
import { ThemeProvider } from "uxfolio/providers/ThemeProvider";

<ThemeProvider modes={{/* e.g. Color: "Dark" */}}>
  <App />
</ThemeProvider>;
```
